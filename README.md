# نظام إدارة المدرسة - School Management System

نظام متكامل لإدارة المدارس الأهلية بواجهة عصرية ودعم كامل للغة العربية.

## المميزات

- 🎓 إدارة الطلاب وأولياء الأمور
- 📊 لوحات تحكم تفاعلية
- 💰 إدارة مالية متكاملة (رسوم، سندات، رواتب)
- 📝 رصد الدرجات والنتائج
- 📅 إدارة الجداول والواجبات
- 🔔 نظام إشعارات داخلي
- 🔒 نظام صلاحيات متكامل (RBAC)
- 📄 تقارير وطباعة مباشرة
- 🔄 مزامنة Offline-First

## المتطلبات

- Python 3.13+
- PostgreSQL 13+
- pip
